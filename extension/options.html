Scientific & Research Purpose

MindPulse is developed as a University Final Year Project (FYP) in collaboration with Psychology Department researchers. The model evaluates social media text using fine-tuned RoBERTa embeddings, 10-dimensional NRC Emotion Lexicons, and CardiffNLP Irony detection.

🔒 Plain-Language Ethical & Privacy Safeguards

  • Single-Post Manual Trigger Only: Analysis only runs when you manually click "Analyze" on an individual post. There is no automated scanning or feed monitoring.
  • No Persistent Storage: Analyzed post content, handles, and results are never stored in browser memory or database logs.
  • Text-Only Backend Inference: Attached content images are captured for display context inside the popup only and are never transmitted to the backend.
  • No Export/Share Capabilities: Sharing features are intentionally omitted to prevent circulating automated inferential results.
  • Non-Clinical Scope: This extension is strictly an educational research tool and not a clinical diagnostic instrument.
